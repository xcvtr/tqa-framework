# Checkpoint 001 — trend_sma XAUUSD: тройной своп + риск-оптимум

## Вердикт: максимум ROI при MDD ≤ 15%

**Параметры:**
- Старт: 4 000 USD
- Тикер: xauusd (золото)
- Детектор: SMA 35/60, ежедневный close
- Усилители: компаунд (eq-cap 0, lot-step 0.01) + пирамидинг max=2
- Трейлинг: SL 1.5%, arm-pct 1.5%, trail-pct 1.5%
- Risk-pct: **0.020**
- Вход: лимитный ордер (midprice), тройной своп среда→четверг
- Спек/своп: по official PDF AlfaForex (POINT + RUB)
- Маржа: золото 1:19 (5.26%), валюты 1:40 (2.5%)

**Результат: +160.7%, DD 14.86%, 181 сделка**

## Изменения относительно предыдущей версии

1. **Тройной своп** (engine.py close-блок) — каждая ночь среда→четверг за удержание сделки
   умножает форвардные пункты на 3: `swap = pips × sp × shares × (nights + triple_nights×2)`
   - по PDF тройной своп для всех, кроме RUB пар и USDCAD
   - `_triple_nights` считает число переходов среда→четверг в интервале entry→exit

2. **TRIZ-патчи удалены** (site-size по SMA-gap, ATR-60 гейт, ratchet lock) — отклонены ранее
   по ROI/DD; восстановлен чистый champion. `import re`, `SignalView.reason` оставлены (безвредны).

3. **Risk-pct 0.020** — оптимум после тройного свопа (0.0205 даёт DD 16.76% ❌,
   мин. лот 0.01 замыкает пол DD ~15%: 0.012/0.013 дают одинаковые 15.27%).

4. **Спека расширена до 46 инструментов** (tqa_f/data/forex_specs.py) — добавлены
   audnzd, gbpnzd, chfjpy, рублёвые пары, metals, крипто-CFD; quote mapping починен
   (QUOTE_MAP из 9-го элемента кортежа; `_fx_usd` использует QUOTE_MAP).

## Что не работает

- EMA вместо SMA: больше сделок, выше DD, ниже ROI
- Другие SMA-периоды (50/100): похожая ROI, выше DD
- Валютные пары (euraud, audusd): OOS −1 418 пп/сумма, в портфеле DD 31.2%
- Портфель 3 пары: ROI +171%, DD 31.2% ❌
- TRIZ: site-size (+292.4/26.5), ATR-гейт (+121.4/14.9), ratchet (+292.3/26.5) — все хуже по ROI/DD
- DD < 15% на капитале 4 000 с мин. лотом 0.01: только полом риска 0.012–0.013 (DD 15.27%) —
  ниже не опускается; точный вход в 15% — риск 0.020 (14.86)
